# selfh.st submission kit

selfh.st curates a self-hosted apps directory and a weekly newsletter that
regularly features new apps. Submission: open an issue/PR against their apps
list repository (linked from <https://selfh.st/apps/>) or use the contact
form; new-release announcements can also be sent for the weekly roundup.

> **Already submitted** via their Project Launch form — awaiting listing. Keep
> this kit as the reference for the newsletter pitch and later edits instead of
> submitting again. See the status table in [README.md](README.md).

**Name:** qnop

**One-liner:** Document review platform — line-precise PDF/Word annotations,
threaded discussions, version-aware re-anchoring and audit trail.

**Longer blurb (newsletter pitch):**

> qnop replaces the "contract as e-mail attachment, comments in a
> spreadsheet" workflow: reviewers mark up exact lines of a rendered
> document, discuss in threads, and the review can only be closed when every
> annotation is resolved. Uploading a new version re-anchors all existing
> annotations and shows a located diff. Ships as one Docker image (embedded
> SPA) + PostgreSQL + any S3-compatible storage; OIDC SSO, teams/roles,
> anonymized reviews and an audit trail included. AGPL-3.0 Community
> edition — free and complete, not a teaser.
