# AlternativeTo submission kit

Submit at <https://alternativeto.net/manage-item/> (account required).

**Name:** qnop

**Tagline (short):** Self-hosted document review with line-precise annotations

**Description:**

> qnop is a self-hosted document review platform for teams. Upload a PDF or
> Word document, invite reviewers or whole teams, and mark up exact lines and
> regions in the browser. Every annotation carries a threaded Markdown
> discussion and a lifecycle: a review can only be finalized when nothing is
> left open. New document versions re-anchor existing annotations instead of
> orphaning them, and an inter-version diff shows what changed. Roles, teams,
> anonymized review mode, OIDC SSO, a full audit trail and e-mail/in-app
> notifications cover the enterprise side; streaks, achievements and reviewer
> profiles make finishing reviews a habit. Community edition is AGPL-3.0,
> free, and runs from a single Docker image plus PostgreSQL and S3-compatible
> storage.
